# 电流源正负判断 与 串并联等效规则

## 电流源没有固定正负极

- 电压源：有固定 + / −，电压固定。
- 电流源：只有箭头方向（电流方向），电压极性由外电路决定。

## 在方程中如何取号

### 网孔电流法
- 网孔电流方向与电流源箭头**同向** → 网孔电流 = +电流源值
- **反向** → 网孔电流 = −电流源值

### 节点电压法
- 电流源箭头**流入**节点 → 方程右边取正
- **流出**节点 → 取负

## 串并联等效规则（理想源）

| 连接方式 | 等效结果 |
|---------|---------|
| 电流源 **串联** 电压源 | 等效为**电流源** |
| 电压源 **并联** 电流源 | 等效为**电压源** |

记忆：串联看电流，并联看电压。
