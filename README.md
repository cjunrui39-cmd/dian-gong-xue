# 电工学

交互式学习正弦交流电路。本仓库是「电工学」系列，目前第一讲是**相量实验台**。

拖动电阻、电感和电容，改频率和初相，阻抗、电流、相量图、波形和谐振会一起变。适合把相量法从公式变成能看、能算的东西。

## 这一讲：正弦稳态

- 相量：正弦量怎么写成复数，初相和有效值怎么读
- 元件：R、L、C 的阻抗、电抗，以及感抗随频率升高、容抗随频率下降
- 串联：RLC 串联的分压、阻抗角、功率和串联谐振
- 并联：导纳、分流，以及并联谐振
- 练习：用同一套约定做几道定量题

约定：理想集总元件，关联参考方向，正弦稳态。电压、电流用有效值，时间函数用 \(\sin\)。无功功率按感性为正。
